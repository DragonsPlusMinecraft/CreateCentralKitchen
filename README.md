## Welcome to **Create: Central Kitchen**
Welcome to Create: Central Kitchen, a mod offering more tools and methods to automate food processing for other mods in Create.
## Contribute
Feel free to open a PR to either translate the mod or to add another feature! All help is appreciated!

### If you want to help us translate...

Please use the language files for the Minecraft version you want to translate. The 1.19.2 and 1.20.1 versions support different sets of mods, so their translation keys are different.

- [1.19.2 language files](https://github.com/DragonsPlusMinecraft/CreateCentralKitchen/tree/1.19.2/0.5.1-dev/translation)
- [1.20.1 language files](https://github.com/DragonsPlusMinecraft/CreateCentralKitchen/tree/1.20.1/6.0.0-dev/src/main/resources/assets/create_central_kitchen/lang)
