## Create Central Kitchen 1.5.1

Compatibility hotfix for End's Delight 2.6.1.

### Update

* Updated the optional End's Delight integration to require version 2.6.1 or newer when installed.
* Migrated End's Delight drink fluid mappings to the 2.6.1 item registry API.

### Fix

* Fixed the startup crash caused by End's Delight 2.6.1 removing the legacy `ItemRegistry` API (#200).
